# 同桌

一个零依赖的局域网文字与文件共享工具。

## 启动

```bash
chmod +x start.sh
./start.sh
```

终端会显示类似 `http://192.168.1.23:8787` 的地址。让其他设备连接同一个 Wi-Fi，并在浏览器打开这个地址。
页面会显示当前访问地址的二维码，其他设备也可以直接扫码加入。

- 共享文字：编辑后点“保存并同步”；“复制文字”可一键复制文本框内容。
- 文件：支持多选或拖拽上传，保存在 `shared_files/`；可以单独下载，也可以全选后打包为 ZIP 下载。
- 改端口：`python3 server.py --port 9000`

如果其他设备打不开，请允许系统防火墙放行 Python 的 8787 端口，并确认路由器没有开启“客户端隔离”。

二维码由系统的 `qrencode` 离线生成。如果页面没有显示二维码，请先安装：`sudo apt install qrencode`。
